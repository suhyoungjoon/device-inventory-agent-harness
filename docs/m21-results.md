- Supervisor는 다른 원인(제조사 C 공급 한도)에 집중해 "제조사 C 초·중반 이동평균 2주 + 단종 예정 선매입" 구간 조건을 1번으로 추천했다(−0.43%p). 플래그십 안전재고 안은 추가 개선 0.1%p를 위해 과잉재고·구매 금액 증가를 허용할지 사람에게 물었다.

## 4. 해석과 다음 손볼 곳 (이번 단계에서는 바꾸지 않음)

1. **결품 구간을 먼저 보게 하기.** 분석 시스템 프롬프트는 코어 공통이라 "실패 사유" 중심이다. 재고 도메인은 핵심 문제가 결품이므로, 도메인 쪽(`analysis_perspectives.yaml`의 결품 패턴 관점 사용, 또는 도메인 명세·차원 설명)에서 `stockout_by`를 먼저 쓰게 하면 P1·P4 탐지가 늘 것으로 본다. 관점별 분석(perspectives=true)은 이번에 돌리지 않았다.
2. **개선 폭.** 개선 에이전트가 허용 범위(안전재고 0~4주) 안에서 작은 값만 냈다. 미리 돌려보기 결과를 보고 값을 키우는 시도(득실 지도·최소 변경)를 더 쓰게 하는 것은 코어 프롬프트 영역이라 이번 범위 밖이다.
3. 반복 1회씩이라 편차가 크다(고정 흐름 두 번: 1개 / 2개 탐지). 발표 수치로 쓰려면 3회 반복을 권한다 (예상 비용 약 $4).
